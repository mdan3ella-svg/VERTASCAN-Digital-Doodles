Spatial Intelligence

Feasibility, intelligent space planning, spatial relationships and conceptual building analysis.

Built as a standalone browser-based tool, SEQUENCE has its own application interface and software capabilities. It can launch directly without opening another suite component first.

Feature areas

Features identified in the supplied source implementation. Availability and robustness of individual commands still require interaction testing.

  • Interactive adjacency-based space planning
  • Room and programme organisation
  • Area and feasibility metrics
  • Conceptual 3D massing and envelope studies
  • Space Lab and discipline concepts
  • Planning model interchange

Designed for

Architects, urban designers, feasibility teams. The software is one independent phase of the NEXFORM design-to-presentation journey. Each component retains its own save/export commands and interface.

Project hand-off between applications depends on their supported file formats and has not been certified as a lossless round-trip. Save local originals before importing or converting files.

Commercial readiness

Evaluation release based on the supplied HTML application. Branded portal, routing, packaging and source syntax checks do not constitute production acceptance. Perform browser interaction testing, persistence/recovery tests, security review, legal/licensing review and export interoperability tests before commercial launch.

No cloud authentication, billing, managed project database, certified BIM-code compliance, or server-hosted collaboration is provided by this static bundle. Do not represent preliminary engineering outputs as independently certified construction documents.
